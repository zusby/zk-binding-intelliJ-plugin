Reports ZK ViewModel member names in Java string literals that don't match any property or global command.

Checked places:

  • @NotifyChange, @SmartNotifyChange and @DependsOn values: the property must exist in the enclosing class or its superclasses.
  • BindUtils.postNotifyChange(queue, scope, bean, "name"): the property must exist on bean's type.
  • BindUtils.postGlobalCommand(queue, scope, "name", args): a @GlobalCommand handler with that name must exist.

A misspelled name is not a compile error and fails silently at runtime: the bound component is never refreshed.

Example:

@Command
@NotifyChange("selectedItme") // typo: the UI never updates
public void select() { ... }

The quick fix creates the missing property (field, getter and setter).
